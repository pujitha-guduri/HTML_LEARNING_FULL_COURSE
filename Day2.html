1. What is HTML?

HTML stands for HyperText Markup Language.

HTML is used to create and structure web pages.

తెలుగులో: వెబ్ పేజీలను నిర్మించడానికి HTML ఉపయోగిస్తాము.

Why do we use HTML?

  • To create headings and paragraphs.
  • To add images, links and tables.
  • To create forms and lists.
  • To structure web page content.

2. History of HTML

HTML was created by Tim Berners-Lee in 1991.

It was developed to share information through the World Wide Web.

తెలుగులో: వెబ్ పేజీల ద్వారా సమాచారాన్ని పంచుకోవడానికి HTML రూపొందించబడింది.

3. Versions of HTML

  1. HTML 1.0 - 1993
  2. HTML 2.0 - 1995
  3. HTML 3.2 - 1997
  4. HTML 4.01 - 1999
  5. XHTML 1.0 - 2000
  6. HTML5 - 2014

HTML5 introduced useful features such as audio, video and semantic tags.

4. Basic Structure of an HTML Document

<!DOCTYPE html>
<html lang="en">
    <head>
        <title>My First Page</title>
    </head>
    <body>
        <h1>Hello World</h1>
        <p>Welcome to HTML</p>
    </body>
</html>

Explanation of HTML Structure

  • DOCTYPE: Tells the browser that this is an HTML5 document.
  • html: Root element of an HTML page.
  • head: Contains page information.
  • title: Displays the page title in the browser tab.
  • body: Contains visible page content.

5. Important Points

  1. HTML is a markup language, not a programming language.
  2. HTML uses tags to structure content.
  3. Most HTML elements have opening and closing tags.
  4. HTML files are saved with the .html extension.
