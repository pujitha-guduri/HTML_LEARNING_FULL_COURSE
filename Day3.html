1. Heading Tags (h1 to h6)

Definition: Heading tags are used to display titles and subtitles.

తెలుగు: వెబ్ పేజీలో శీర్షికలు రాయడానికి ఉపయోగిస్తాము.

Why: To organize content with different heading levels.

Shortcut in VS Code

Type h1 and press Tab.

Expanded code: <h1></h1>

Example and Output

Heading 1

Heading 2

Heading 3

Heading 4

Heading 5
Heading 6

2. Paragraph Tag (p)

Definition: The p tag is used to write paragraphs.

తెలుగు: పేరాగ్రాఫ్ రాయడానికి ఉపయోగిస్తాము.

Why: To display text as separate paragraphs.

Shortcut: Type p and press Tab.

Example:

HTML is used to create web pages.

Welcome to my learning portal.

3. Preformatted Tag (pre)

Definition: The pre tag preserves spaces and line breaks.

తెలుగు: మనం ఇచ్చిన ఖాళీలు మరియు లైన్ మార్పులను అలాగే చూపిస్తుంది.

Shortcut: Type pre and press Tab.

Name: Pujitha
Course: HTML
Day: 3

4. Line Break Tag (br)

Definition: The br tag breaks a line.

తెలుగు: కొత్త లైన్‌లో text రావడానికి ఉపయోగిస్తాము.

Shortcut: Type br and press Tab.

Hello Pujitha!
Welcome to HTML.
Keep Practicing!

Note: br is a void element. It does not need a closing tag.

5. Horizontal Rule Tag (hr)

Definition: The hr tag creates a horizontal line between sections.

తెలుగు: రెండు sections మధ్య అడ్డ గీత చూపించడానికి ఉపయోగిస్తాము.

Shortcut: Type hr and press Tab.

First Section

Second Section

Note: hr is also a void element.

6. Image Tag (img)

Definition: The img tag displays an image on a web page.

తెలుగు: వెబ్ పేజీలో ఫోటో చూపించడానికి ఉపయోగిస్తాము.

Shortcut: Type img and press Tab.

Example:

<img src="pujitha.jpg" alt="My Photo" width="200">

Important Attributes

  • src - Specifies the image location.
  • alt - Gives alternative text if image cannot load.
  • width - Sets image width.

Note: Keep pujitha.jpg in the same folder as Day3.html.

7. Audio Tag (audio)

Definition: The audio tag adds sound files to a web page.

తెలుగు: వెబ్ పేజీలో ఆడియో వినడానికి ఉపయోగిస్తాము.

Shortcut: Type audio and press Tab.

Example:

<audio controls>
    <source src="english-learning.ogg" type="audio/ogg">
</audio>

Important Attribute

  • controls - Displays play and pause controls.
  • src - Specifies the audio file location.

8. Video Tag (video)

Definition: The video tag displays video files on a web page.

తెలుగు: వెబ్ పేజీలో వీడియోలు చూడడానికి ఉపయోగిస్తాము.

Shortcut: Type video and press Tab.

Example:

<video width="320" controls>
    <source src="learning-video.mp4" type="video/mp4">
</video>

Important Attributes

  • controls - Displays video controls.
  • width - Sets video width.
  • height - Sets video height.
  • src - Specifies the video file location.

Important Points

  1. HTML provides six heading tags.
  2. Paragraph tag is used for text.
  3. Pre tag preserves spaces and line breaks.
  4. Br tag creates a line break.
  5. Hr tag creates a horizontal line.
  6. Img tag displays images.
  7. Audio tag plays audio files.
  8. Video tag plays video files.
