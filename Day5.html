5. HTML Iframe

Definition: Iframe is used to display another webpage inside the current webpage.

తెలుగు: ఒక వెబ్ పేజీలో మరొక వెబ్ పేజీని చూపించడానికి Iframe ఉపయోగిస్తాము.

Important Attributes

  • src - Specifies webpage location.
  • width - Sets width.
  • height - Sets height.
  • title - Gives description.
