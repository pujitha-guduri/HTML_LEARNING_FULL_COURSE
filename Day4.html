1. Text Formatting Tags

Definition: Text formatting tags are used to change the appearance and meaning of text in a web page.

తెలుగు: వెబ్ పేజీలో text ను వివిధ రకాలుగా చూపించడానికి Text Formatting Tags ఉపయోగిస్తాము.

1. Bold Tag (b)

Used to display text in bold.

తెలుగు: అక్షరాలను మందంగా చూపిస్తుంది.

Example: This is Bold Text

2. Strong Tag (strong)

Used to indicate important text.

తెలుగు: ముఖ్యమైన సమాచారాన్ని సూచిస్తుంది.

Example: Important Information

3. Italic Tag (i)

Used to display text in italic style.

తెలుగు: అక్షరాలను వాలుగా చూపిస్తుంది.

Example: This is Italic Text

4. Emphasis Tag (em)

Used to emphasize a word or sentence.

తెలుగు: ఒక పదానికి లేదా వాక్యానికి ప్రాధాన్యత ఇస్తుంది.

Example: Practice Every Day

5. Underline Tag (u)

Used to underline the text.

తెలుగు: అక్షరాల కింద గీతను చూపిస్తుంది.

Example: HTML Learning

6. Mark Tag (mark)

Used to highlight important text.

తెలుగు: ముఖ్యమైన పదాలను Highlight చేస్తుంది.

Example: Learn HTML

7. Small Tag (small)

Used to display smaller text.

తెలుగు: చిన్న అక్షరాలలో text చూపిస్తుంది.

Example: This is Small Text

8. Delete Tag (del)

Used to show deleted text with a line through it.

తెలుగు: తొలగించిన text ను గీతతో చూపిస్తుంది.

Example: Old Price: 500

9. Insert Tag (ins)

Used to show inserted text with an underline.

తెలుగు: కొత్తగా చేర్చిన text ను underline తో చూపిస్తుంది.

Example: New Price: 400

10. Subscript Tag (sub)

Used to display text slightly below the normal line.

తెలుగు: అక్షరాలను సాధారణ లైన్ కంటే కింద చూపిస్తుంది.

Example: H2O

11. Superscript Tag (sup)

Used to display text slightly above the normal line.

తెలుగు: అక్షరాలను సాధారణ లైన్ కంటే పైన చూపిస్తుంది.

Example: X2

12. Break Tag (br)

Used to move text to the next line.

తెలుగు: కొత్త లైన్ లో text చూపిస్తుంది.

My Name is Pujitha.
I am learning HTML.
I love coding.

2. HTML Table Tags

Definition: A table is used to display data in rows and columns.

తెలుగు: సమాచారాన్ని Rows మరియు Columns రూపంలో చూపించడానికి Table ఉపయోగిస్తాము.

Important Table Tags

  • table: Creates a table.
  • tr: Creates a table row.
  • th: Creates a table heading.
  • td: Creates a table data cell.
  • caption: Adds a title to the table.

Table Structure Example

Student Details
Name Age Course
Pujitha 22 HTML
Jyothi 22 Python
Priya 21 SQL

Why Do We Use Table Tags?

  • table - To create a table.
  • tr - To create rows.
  • th - To display headings.
  • td - To display data.
  • caption - To give a table title.
