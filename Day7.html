Form Validation, Semantic Tags and Meta Tags

1. Form Validation

English: Form Validation checks whether user input is correct.

తెలుగు: User ఇచ్చిన సమాచారం సరైనదో కాదో పరీక్షించడాన్ని Form Validation అంటారు.

Important Attributes

  • required - Makes a field mandatory.
  • pattern - Defines a valid input format.
  • title - Displays additional instructions.
  • placeholder - Shows hint text.

2. Semantic HTML5 Tags

English: Semantic tags clearly describe the meaning of webpage content.

తెలుగు: Webpage లోని ప్రతి భాగం యొక్క అర్థాన్ని స్పష్టంగా తెలియజేసే tags ను Semantic Tags అంటారు.

Important Semantic Tags

  • header - Defines the header section.
  • nav - Defines navigation links.
  • main - Defines main content.
  • section - Groups related content.
  • article - Defines independent content.
  • aside - Defines additional content.
  • footer - Defines footer information.

3. HTML Meta Tags

English: Meta tags provide information about a webpage.

తెలుగు: Webpage గురించి అదనపు సమాచారాన్ని Browser మరియు Search Engines కు తెలియజేస్తాయి.

Important Meta Tags

  • charset - Defines character encoding.
  • viewport - Helps webpages adjust to screen sizes.
  • description - Describes the webpage.
  • keywords - Provides webpage keywords.
  • refresh - Refreshes or redirects a webpage.

Example

Meta tags are written inside the head section of HTML.

Example: <meta charset="UTF-8">
