1. HTML Hyperlinks

Definition:

Hyperlinks are used to connect one webpage to another webpage or website.

తెలుగు అర్థం:

ఒక Webpage నుండి మరొక Webpage కి వెళ్లడానికి ఉపయోగించే links ను Hyperlinks అంటారు.

Why do we use Links?

Links help users navigate between webpages and websites.

Syntax:

<a href="URL">Link Text</a>

Example:

Open Google

Important Attribute:

  • href - Specifies the destination URL.
  • target="_blank" - Opens the link in a new tab.

2. Email Links

English: Email links open an email application to send an email.

తెలుగు: Email పంపడానికి ఉపయోగించే links ను Email Links అంటారు.

Syntax:

<a href="mailto:email@example.com">Send Email</a>

4. Phone Links

English: Phone links allow users to call a phone number.

తెలుగు: Phone number పై click చేసి call చేయడానికి Phone Links ఉపయోగిస్తాము.

Syntax:

<a href="tel:+91XXXXXXXXXX">Call Us</a>

Note: Replace XXXXXXXXXX with an actual phone number.

6. HTML Image Mapping

Definition:

Image Mapping allows users to click on specific areas of an image to open different links.

తెలుగు అర్థం:

ఒక Image లోని నిర్దిష్ట భాగాలపై click చేస్తే వేర్వేరు links open అయ్యే విధానాన్ని Image Mapping అంటారు.

Important Tags:

  • img - Displays an image.
  • map - Defines an image map.
  • area - Defines a clickable area.
  • usemap - Connects an image with a map.
